## P · Plan

### 第一性原理判断

当前约束不再是“能否被抓取”，而是：

1. 真实搜索可见度过低；
2. 主题权威页数量不足，叶子页过多；
3. 外链相关性与权威度不足；
4. 缺少真实查询、索引、点击和引用的经营测量。

### 当前阶段目标

1. 让 about / principles / quotes / books 成为主战场页面；
2. 让章句页更多承担证据职责，而非单独承担获客职责；
3. 建立可复盘的 GSC / Bing / GA4 周期检查；
4. 逐步把“语料库”升级为“可引用的孟子知识站”。

### 核心指标

#### 站内结构指标

- about / principles / quotes / books 四类页面都必须具备：
  - 明确主题定位；
  - 直接回答；
  - 进入路径；
  - FAQ 结构；
  - 回到原典的内链。

#### 搜索经营指标

- GSC 已接入；
- Bing Webmaster 已接入；
- 至少 20 个可跟踪查询；
- 每周能看到：
  - 新索引页；
  - 高展示低点击页；
  - 主题页与章句页分层表现。

#### 权威指标

- 新增真实相关引用域；
- 新增被引用主题页；
- 头部主题页 CTR 改善。

## C · Check

### 每周检查

1. GSC：
   - 新增索引页；
   - 未索引页；
   - 高展示低点击页；
   - 新增查询；
   - about / principles / quotes / books 表现。

2. Bing Webmaster：
   - 抓取异常；
   - 索引覆盖；
   - 搜索查询变化。

3. 站内回归：
   - `npm test`；
   - 抽查主页、四类主战场页、4 个重点章句页的 title / description / FAQ / 内链。

4. 权威建设：
   - 新增引用域数；
   - 新增相关编辑型链接；
   - 是否出现与哲学、教育、汉学相关的真实外链。

### 每月检查

1. 哪些主题页开始获得真实展示；
2. 哪些主题词仍由章句页意外承接；
3. 哪些页面曝光高但 CTR 低；
4. 哪些页有点击但停留/继续阅读差；
5. 是否需要新建主题页，而不是继续扩充叶子页。

## A · Act

### 触发条件与动作

#### 如果主题页有展示但 CTR 低

- 重写 title / description；
- 强化首屏一句话定义；
- 强化第一屏的“为什么重要”和“从哪里进入”。

#### 如果章句页获得展示但查询意图更适合主题页

- 给章句页增加更强的主题回链；
- 在主题页增加更强的章句证据链接；
- 调整主题页首屏与 FAQ，使其更适合承接该查询。

#### 如果外链继续主要来自无关 SEO 域

- 暂停任何低质量外链动作；
- 转向资源页、编辑型文章、教育引用；
- 以主题页为外链目标，而不是随机章句页。

#### 如果整卷页性能开始恶化

- 优先处理 HTML 体量；
- 考虑分段渲染、折叠目录、摘要首屏；
- 保留全文可访问性，但减少首屏负担。

## 当前结论

2026-08-20 当前站点已经越过技术 SEO 基础阶段。  
从这一刻开始，真正要管理的是：

1. 主战场页面是否足够强；
2. 真实搜索数据是否被持续看见；
3. 主题权威是否在外部世界成立；
4. 每一轮修改是否能回到 PDCA 周期里被验证。
